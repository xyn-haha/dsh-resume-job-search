# cover_letters/ 求职信目录约定

- `cover_<公司>_<岗位>.md`：简体中文岗位写中文，英文岗位写英文（语言跟随 JD）。
- LaTeX 路线保留 `cover_<公司>_<岗位>.tex`，模板来源见 `skills/cover-letter/SKILL.md`。

硬性要求（详见技能文件）：

1. 篇幅一页内（中文约 400–600 字，英文 250–300 词），签名区必须与正文同页。
2. 称呼准确：能查到招聘负责人就写姓名；查不到用「尊敬的招聘负责人」/`Dear Hiring Manager`。
3. 禁用破折号、套话（「充满热情」「非常合适」）、无支撑夸张词、道歉式表述。
4. 每一处公司相关说法都必须独立核实，未核实则改写或删除。
5. 正文必须把具体项目经历对应到岗位要求，引用真实指标，禁止虚构。
