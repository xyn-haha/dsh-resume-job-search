# 候选人资料库（Candidate Profile）

个人资料是整条求职链路的事实底本。**评估岗位匹配度、改写简历、撰写求职信、准备面试，都必须先读本文件**，任何未在本文件中登记的能力、经历、成果都视为不存在。

## 使用方式

1. 首次使用时，按下面模板**逐项向用户提问**并填写真实内容。
2. 每次用户提到新的经历、证书、获奖或技能，先更新本文件，再改简历。
3. 未确认的字段保持 `待补充`，**不要用推测内容填充**。
4. 涉及论文、专利、比赛名次的表述，保留原始名称与准确年份，不做美化。

## 硬性纪律

1. **禁止编造**：不存在的技能、经历、证书、名次一律不得写入简历或求职信；用户口头描述与实际材料不一致时，以可证明的材料为准并提示用户。
2. **隐私最小化**：只收集求职必需的字段；身份证号、家庭住址、银行卡等敏感信息不登记。对外投递的简历建议隐去精确住址与手机号中间位（按投递平台要求调整）。
3. **来源可追溯**：每条关键经历都应能指向一个证明材料（仓库、证书、比赛页面、实习证明）。找不到证明材料的条目，标记为「待补证明」并在评估时按较低置信度处理。
4. **更新留痕**：修改本文件后，在文件末尾的「变更记录」追加一行日期与改动摘要。
